# 🎉 בוט ימי הולדת משפחתי לוואטסאפ ועמוד נחיתה מעוצב

מערכת מלאה, מעוצבת וחמה למשפחה: עמוד נחיתה מרהיב להזנת ימי הולדת + בוט וואטסאפ אוטומטי ששולח ברכות מעוצבות לקבוצה המשפחתית בכל בוקר.

---

## 🌟 מה הפרויקט כולל?

1. **עמוד נחיתה משפחתי (`index.html`):**
   - עיצוב נקי, עדין, חם ולא גנרי בעברית מלאה (RTL).
   - מותאם לכל סמארטפון, טאבלט ומחשב.
   - טופס הרשמה קל ומהיר + אפקט קונפטי.
   - סקשן "חוגגים בקרוב" עם ספירה לאחור חיה.
   - לוח ימי הולדת מלא עם חיפוש וסינון לפי חודשים.

2. **בוט וואטסאפ מתוזמן (`bot.js` & `server.js`):**
   - בודק בכל יום בשעה שנקבעה (ברירת מחדל: 08:30) מי חוגג יום הולדת.
   - שותל את שם החוגג, הגיל (אם צויין) ואיחול אישי בתוך תבנית הברכה.
   - שולח אוטומטית הודעה לקבוצה המשפחתית.

3. **עמוד ניהול (`admin.html`):**
   - חיבור וואטסאפ באמצעות סריקת קוד QR פשוטה.
   - אפשרות לשלוח הודעת בדיקה בלחיצת כפתור.
   - שינוי שעת השליחה היומית ושם הקבוצה.
   - עריכת נוסח הברכה.
   - מחיקת רשומות.
   - מוגן בקוד PIN (ברירת מחדל: `1234`).

---

## 🚀 הרצה מקומית במחשב (Local)

1. פתח טרמינל בתיקיית הפרויקט:
   ```bash
   npm start
   ```
2. פתח את הדפדפן בכתובת:
   - **עמוד הנחיתה למשפחה:** `http://localhost:3000`
   - **ממשק הניהול וה-QR:** `http://localhost:3000/admin.html` (קוד כניסה: `1234`)
3. סרוק את קוד ה-QR בוואטסאפ מהטלפון (דרך "מכשירים מקושרים").

---

## ☁️ איך להעלות לשרת חינמי 24/7 (למשל Render.com)?

1. העלה את תיקיית הפרויקט לחשבון **GitHub** שלך (פרטי או ציבורי).
2. הירשם בחינם ל-[Render.com](https://render.com).
3. לחץ על **New +** ➜ **Web Service**.
4. חבר את ה-Repository שלך מ-GitHub.
5. הגדרות:
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
6. לחץ על **Create Web Service**.
7. לאחר שהשרת עולה, תקבל כתובת חינמית (למשל `https://family-birthdays.onrender.com`).
8. כנס ל-`https://family-birthdays.onrender.com/admin.html`, סרוק את ה-QR פעם אחת – וזהו! הבוט יפעל 24/7.
